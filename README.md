# Coffee Oasis Web Project

A multi-week HTML and CSS project created as part of WEBD 101: Introduction to Web Page Construction.

## Project Goals

- Practice writing HTML manually
- Build multi-page website structure
- Apply semantic HTML
- Add and refine CSS styling
- Practice navigation and page organization
- Validate HTML and CSS for correctness
- Track project development with Git and GitHub

## Development Environment

- IntelliJ IDEA
- Google Chrome
- W3C HTML Validator
- Git
- GitHub
